# Credits

## Kode

Dibuat untuk proyek Pixel Puzzle Edukasi.

## Font

Sementara memakai font logis `Monospaced` bawaan sistem (tidak didistribusikan).
Font pixel berlisensi bebas akan ditambahkan di `game/data/fonts/` dan dicatat di sini.

## Gambar

Sementara digambar langsung dengan primitif Processing (rect/teks). Belum ada aset PNG.
Sprite 16x16 buatan sendiri akan ditaruh di `game/data/sprites/` dan dicatat di sini.

## Suara

Belum ada aset suara.

## Lisensi aset

Semua aset yang ditambahkan wajib buatan sendiri atau berlisensi jelas. Catat nama, sumber, dan lisensinya di file ini sebelum repositori dipublikasikan.
